# Networking Fundamentals 🌐

## Project Overview

This repository documents my practical learning journey in Computer Networking using Cisco Packet Tracer.

## Objectives
- Understand basic networking concepts.
- Configure IPv4 addresses.
- Create Local Area Networks (LAN).
- Test network connectivity.
- Understand communication between different networks.

## Tools
- Cisco Packet Tracer

## Practical Activities

### 1. LAN Configuration
Creating a local network connecting computers and network devices.

### 2. IPv4 Configuration
Configuring IP addresses, subnet masks and default gateways.

### 3. Connectivity Testing
Using the `ping` command to verify communication between devices.

### 4. Network Routing
Observing communication between different networks.

- Networking Fundamentals
- IPv4 Addressing
- LAN Configuration
- Network Troubleshooting
- Basic Routing Concepts
